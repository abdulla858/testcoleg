# University Interactive Quiz Platform | منصة الاختبارات الجامعية التفاعلية

منصة ويب تفاعلية ثابتة (Static Web Application) مخصصة للطلاب الجامعيين للتدرب والمذاكرة من خلال بنوك الأسئلة، النماذج التدريبية، والاختبارات النصفية مع تصحيح تلقائي فوري ومراجعة تفصيلية للإجابات مستندة بنسبة 100% إلى ملفات المحاضرات الرسمية.

---

## 🌟 المبدأ الأساسي للمشروع

> **المحاضرات الجامعية هي المصدر الوحيد والحصري للمعلومات والأسئلة.**
> لا يتم جلب أي أسئلة أو معلومات من مصادر خارجية أو عامة أو تخمين أي إجابات خارج نطاق ما ورد في المحاضرات المعتمدة.

```text
ملفات المحاضرات (PDF / DOCX / PPTX / TXT)
                  ↓
          استخراج المحتوى الدقيق
                  ↓
       إنشاء الأسئلة مع توثيق المصدر
                  ↓
      تحديث ملفات البيانات (JSON)
                  ↓
       نشر الموقع عبر GitHub Pages
                  ↓
       استخدام الطلاب وحل الاختبارات
```

## 🚀 المميزات الرئيسية

- **معمارية خفيفة وسريعة (Static 100%):** تعمل مباشرة عبر **GitHub Pages** بدون أي Backend أو Database Server.
- **تنوع أشكال التدريب:**
  - **بنوك الأسئلة (Question Banks):** تصفح وحل أسئلة حسب المادة والمحاضرة.
  - **النماذج التدريبية (Training Models):** نماذج اختبارات جاهزة ومحددة بعدد أسئلة ووقت محدد.
  - **الاختبارات النصفية (Midterms):** نماذج محاكية للاختبارات النصفية الفعلية.
- **محرك اختبارات تفاعلي ومتطور:**
  - واجهة تقدم واضحة ونظيفة (Progress Bar).
  - دعم عدة أنواع من الأسئلة (اختيار من متعدد، صح وخطأ، اختيار متعدد، ملء الفراغ).
  - إمكانية التبديل بين الأسئلة ومراجعتها قبل التسليم.
  - مؤقت زمني اختياري/محدد حسب النموذج.
- **تصحيح تلقائي فوري:**
  - حساب الدرجات والنسبة المئوية، مع إحصائيات دقيقة (صحيحة، خاطئة، غير مجاب عنها).
- **مراجعة الإجابات وتوثيق المصدر:**
  - عرض الإجابة الصحيحة وشرحها.
  - إبراز مصدر كل سؤال بدقة (اسم المادة، رقم المحاضرة، الصفحة، القسم).
- **حفظ تقدم الطالب محلياً:**
  - تخزين نتائج الاختبارات وإحصائيات الطالب داخل المتصفح عبر `LocalStorage` للحفاظ على الخصوصية وعدم الحاجة لأي خادم.
- **واجهة مستخدم عصرية وفاخرة (RTL):**
  - دعم أصيل للغة العربية والاتجاه من اليمين لليسار.
  - تصميم متجاوب بالكامل (Mobile, Tablet, Desktop).
  - دعم الوضع الليلي (Dark Mode) والوضع النهاري (Light Mode).
- **تشغيل بدون خادم (100% Offline & File Protocol Ready):**
  - تضمن المنصة ملف `js/static-data.js` الذي يحتوي على كامل قاعدة البيانات المدمجة مما يسمح بتشغيل الموقع مباشرة بالنقر المزدوج على `index.html` أو رفعه كصفحات ثابتة على GitHub Pages.

## 💻 طريقة التشغيل محلياً (Local Development)

بما أن المشروع عبارة عن **Static Web Application**، يمكنك تشغيله باستخدام أي خادم ويب محلي بسيط (لتجنب قيود CORS عند استخدام `fetch` على ملفات JSON المحلية):

### باستخدام Visual Studio Code:
1. ثبّت إضافة **Live Server**.
2. اضغط بالزر الأيمن على ملف `index.html` واختر **Open with Live Server**.

### باستخدام Python:
```bash
# في مسار المشروع الرئيسي
python -m http.server 8000
```
ثم افتح المتصفح على: `http://localhost:8000`

### باستخدام Node.js (npx):
```bash
npx serve .
```

## 🌐 النشر على GitHub Pages

المشروع مصمم ليعمل مباشرة وبسلاسة على **GitHub Pages**:
1. أنشئ مستودعاً جديداً على GitHub باسم المشروع (مثلاً: `university-quiz-platform`).
2. ارفع ملفات المشروع إلى الفرع الرئيسي (`main` أو `master`).
3. توجه إلى إعدادات المستودع **Settings** > **Pages**.
4. اختر المصدر: **Deploy from a branch**.
5. حدد الفرع: `main` والمجلد: `/ (root)` ثم احفظ.
6. سيكون الموقع متاحاً على الرابط:
   `https://<USERNAME>.github.io/<PROJECT-NAME>/`

> **تنبيه للمسارات النسبية:** تم استخدام المسارات النسبية (مثل `./data/questions.json` و `./css/main.css`) لضمان عمل الموقع دون أي مشاكل مسارات على GitHub Pages.

## 📝 دليل إضافة وتحديث المحتوى

### 1. إضافة محاضرات وأسئلة جديدة
عند تزويد Antigravity بملفات محاضرات جديدة:
1. يتم تحليل المحتوى واستخراج الأفكار والمفاهيم.
2. يتم صياغة الأسئلة وربط كل سؤال بمصدره الدقيق (رقم الصفحة والمقطع).
3. يتم إدراج المادة في `data/courses.json` والمحاضرة في `data/lectures.json`.
4. تُضاف الأسئلة إلى `data/questions.json` مع تجنب أي تكرار.
5. تُحدّث بنوك الأسئلة في `data/question-banks.json`.

### 2. إضافة نموذج اختبار أو اختبار نصفي
- يتم إضافة النموذج في `data/models.json` أو `data/midterms.json` مع تحديد:
  - معرّف النموذج `id`.
  - المادة والمحاضرات المشمولة.
  - عدد الأسئلة والمدة الزمنية المخصصة بالدقائق.
  - معايير أو قائمة معرّفات الأسئلة.

## 🛡️ الخصوصية والأمان

- المنصة لا تستخدم أي خوادم خارجية، ولا تجمع أو ترسل أي بيانات خاصة بالطلاب.
- نتائج الاختبارات تحفظ فقط على متصفح جهاز الطالب باستخدام `LocalStorage`.
- لا توجد أي مفاتيح سرية (API Keys) أو بيانات حساسة داخل كود الواجهة.
