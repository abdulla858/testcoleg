# نظرة عامة على المشروع (Project Overview)

## 1. التعريف بالمشروع
**اسم المشروع:** منصة الاختبارات الجامعية التفاعلية (University Interactive Quiz Platform).  
**النوع:** تطبيق ويب ثابت (Static Web Application).  
**الهدف الأساسي:** تمكين طلاب الجامعة من التدرب والمذاكرة الفعالة لمقرراتهم الدراسية، من خلال حل اختبارات تجريبية تفاعلية تعتمد بنسبة 100% على محتوى محاضراتهم الرسمية دون أي مصادر خارجية.

---

## 2. الرؤية والأهداف
1. **الاعتمادية والموثوقية المطلقة:** تقديم أسئلة موثوقة ومربوطة بمصادرها الدقيقة داخل المحاضرات (رقم المحاضرة، الصفحة، الفقرة)، لمنع أي تشتيت أو تعارض مع المنهج الدراسي الفعلي.
2. **السهولة والوصول المباشر:** موقع ويب سريع وخفيف يعمل على أي جهاز (حاسوب، جهاز لوحي، هاتف ذكي) بمجرد فتح الرابط دون الحاجة إلى تسجيل دخول، تثبيت برامج، أو الاتصال بقواعد بيانات معقدة.
3. **أشكال تقييم متنوعة:** تقديم المحتوى التعليمي عبر ثلاثة مسارات تدريبية:
   - **بنوك الأسئلة (Question Banks):** تصفح شامل للأسئلة مقسمة حسب المحاضرة أو مجمعة.
   - **النماذج التدريبية (Training Models):** نماذج محددة بوقت وعدد أسئلة للتدريب الذاتي.
   - **الاختبارات النصفية (Midterms):** نماذج تحاكي اختبارات منتصف الفصل بدقة.
4. **التصحيح الفوري والمراجعة:** حصول الطالب على تقييم فوري يوضح إجاباته الصحيحة والخاطئة مع تعليل كل إجابة ومصدرها.

---

## 3. الفلسفة المعمارية
- **خالٍ من الـ Backend:** لا توجد خوادم Node.js، PHP، Python Backend، ولا قواعد بيانات مثل MySQL أو MongoDB.
- **الاستضافة عبر GitHub Pages:** استضافة سريعة، مجانية، دائمة، وآمنة.
- **فصل البيانات عن المنطق العرضي:** حفظ كافة بيانات المقررات والأسئلة في ملفات JSON منظمة، والواجهة تقوم بقراءتها ديناميكياً باستخدام Fetch API.
- **حفظ حالة الطالب محلياً:** يتم تخزين نتائج الاختبارات وإحصائيات الإنجاز داخل `LocalStorage` في متصفح المستخدم دون نقل أي بيانات خاصة لأي طرف خارجي.

---

## 4. الجمهور المستهدف
- **طلاب الجامعات:** الذين يرغبون في تقييم مدى استيعابهم للمحاضرات ومراجعة المواد قبل الاختبارات الفصلية والنهائية.
- **مجموعات الدراسة:** لمشاركة الاختبارات ومقارنة النتائج والتدرب المشترك.
