# مواصفات محرك الاختبارات (Quiz Engine Specification)

## 1. الغرض والمسؤولية
يقوم محرك الاختبارات (`js/quiz.js` و `js/results.js`) بإدارة دورة حياة جلسة الاختبار بالكامل من لحظة التحميل وحتى عرض النتائج وتوثيق المراجعة.

---

## 2. آلة حالة الاختبار (Quiz State Machine)

```text
       [ الخمول IDLE ]
              │  (تحميل معرّف النموذج أو البنك)
              ▼
      [ جلب البيانات FETCHING ]
              │  (تحميل الأسئلة وقراءتها)
              ▼
       [ الجلسة نشطة ACTIVE ] ◄──┐
              │                   │ (التنقل بين الأسئلة،
              │                   │  تسجيل الإجابات، تحديث المؤقت)
              ▼                   │
    [ تأكيد التسليم CONFIRM ] ───┘
              │  (تأكيد التسليم أو نفاد الوقت)
              ▼
      [ التصحيح GRADING ]
              │  (حساب الدرجات والمقارنة)
              ▼
   [ عرض النتيجة والمراجعة REVIEW ]
              │
              ▼
    [ حفظ النتيجة في LocalStorage ]
```

---

## 3. تفاصيل إدارة الحالة (State Properties)
- `quizType`: نوع الاختبار (`bank`, `model`, `midterm`).
- `quizMetadata`: بيانات الاختبار (العنوان، المادة، الوقت المحدد بالدقائق).
- `questions`: مصفوفة كائنات الأسئلة النشطة.
- `currentIndex`: رقم السؤال المعروض حالياً (0-indexed).
- `userAnswers`: كائن يخزن إجابات الطالب مفهرسة بمعرف السؤال (`{ [questionId]: answerValue }`).
- `timer`:
  - `timeRemaining`: الثواني المتبقية.
  - `intervalId`: معرّف دالة التحديث التكرارية.
- `status`: حالة الاختبار الحالية (`loading`, `in_progress`, `completed`).

---

## 4. منطق التصحيح (Grading Algorithm)
لكل سؤال في قائمة الاختبار:
1. استرجاع إجابة الطالب من `userAnswers[question.id]`.
2. مقارنة إجابة الطالب مع `question.correctAnswer`:
   - **اختيار من متعدد وصح وخطأ:** تطابق مباشر لقيمة الفهرس الرقمي (`userAnswer === question.correctAnswer`).
   - **اختيار متعدد:** مطابقة تامة لمصفوفة الفهارس المختارة بصرف النظر عن الترتيب.
   - **ملء الفراغ:** تطابق نصي مع تجاهل الفراغات الزائدة وحالة الأحرف وعلامات الترقيم.
3. تجميع الإحصائيات:
   - `totalQuestions`: إجمالي عدد الأسئلة.
   - `correctCount`: عدد الإجابات الصحيحة.
   - `wrongCount`: عدد الإجابات غير الصحيحة.
   - `skippedCount`: عدد الأسئلة التي تركت فارغة.
   - `percentage`: `(correctCount / totalQuestions) * 100`.
   - `passed`: `percentage >= (passingPercentage || 60)`.

---

## 5. مراجعة الإجابات (Answer Review)
بعد اكتمال التصحيح، يتم توليد عناصر المراجعة التفصيلية لكل سؤال:
- نص السؤال بالكامل.
- الإجابة التي اختارها الطالب (مع أيقونة وتلوين توضيحي).
- الإجابة الصحيحة المعتمدة.
- التعليل والشرح العلمي (`explanation`).
- بطاقة المصدر الدقيقة (`source: { lecture, page, section }`).
