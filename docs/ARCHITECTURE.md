# المعمارية التقنية والتصميم (Architecture Specification)

## 1. النمط المعماري (Architecture Pattern)

تعتمد المنصة على معمارية **تطبيق ويب ثابت خفيف وموزع (Client-Side Static Web Application)** يعمل بالكامل داخل متصفح المستخدم دون الحاجة إلى أي خوادم معالجة خلفية (Serverless / Backend-Free).

```text
┌──────────────────────────────────────────────────────────────┐
│                    GitHub Pages Host                         │
│  ┌──────────────┐   ┌──────────────┐   ┌──────────────────┐  │
│  │ HTML Pages   │   │ CSS Assets   │   │ Static JSON Data │  │
│  │ (Templates)  │   │ (Styles)     │   │ (Data Store)     │  │
│  └───────┬──────┘   └──────┬───────┘   └────────┬─────────┘  │
└──────────┼─────────────────┼────────────────────┼────────────┘
           │                 │                    │
           ▼                 ▼                    ▼ (Fetch API)
┌──────────────────────────────────────────────────────────────┐
│                    Client Browser                            │
│  ┌────────────────────────────────────────────────────────┐  │
│  │                  JavaScript Core Modules               │  │
│  │  - app.js (Theme, Navigation, Global State)            │  │
│  │  - data.js (JSON Fetcher, Cache, LocalStorage Manager) │  │
│  │  - quiz.js (Quiz Engine, Timer, State Machine)         │  │
│  │  - results.js (Scorer, Review Generator)               │  │
│  └────────────────────────────────────────────────────────┘  │
│                                                              │
│  ┌────────────────────────────────────────────────────────┐  │
│  │                     LocalStorage                       │  │
│  │  - quiz_history (Last tests, scores, timestamps)       │  │
│  │  - user_settings (Theme preference, font size)         │  │
│  └────────────────────────────────────────────────────────┘  │
└──────────────────────────────────────────────────────────────┘
```

## 2. مبادئ التصميم التقني

### 2.1 انعدام الخادم (Zero-Backend)
- لا توجد أي واجهات برمجة تطبيقات مخصصة (Custom REST APIs).
- لا توجد قواعد بيانات SQL أو NoSQL مدارة على الخادم.
- جميع عمليات القراءة تتم مباشرة لملفات JSON الثابتة.

### 2.2 التوافق المطلق مع GitHub Pages (URL Path Portability)
- يُمنع تماماً استخدام المسارات المطلقة من جذر الخادم (مثل `/css/style.css` أو `/api/data`).
- تستخدم جميع الاستدعاءات والروابط مسارات نسبية ذكية (مثل `./data/courses.json` أو `../css/main.css`) لضمان عمل الموقع داخل مجلد فرعي في GitHub Pages (مثل `https://username.github.io/repo-name/`).

### 2.3 النقاء البرمجي (Vanilla Web Standards)
- **HTML5:** بناء دلالي (Semantic Markup) يدعم قارئات الشاشة والوصولية وسهولة القراءة.
- **CSS3:** نظام متغيرات تصميم حديث (CSS Custom Properties) يدعم الوضعين الداكن والفاتح، والاتجاه من اليمين لليسار (RTL) دون الاعتماد على مكتبات ضخمة.
- **JavaScript ES6+:** استخدام الوحدات النمطية، والـ Fetch API، والـ Promises للتعامل مع البيانات والمنطق.

## 3. وحدات المنطق البرمجي (Module Breakdown)

1. **`app.js`**:
   - التهيئة العامة للصفحة.
   - التحكم بشريط التنقل والقائمة المتجاوبة.
   - إدارة الوضع الليلي (Dark Mode Toggle) ومزامنة الثيم.
2. **`data.js`**:
   - نقطة الاتصال المركزية لقراءة وتخزين البيانات.
   - دوال تحميل ملفات JSON مع معالجة الأخطاء والتخزين المؤقت في الذاكرة (Memory Cache).
   - توفير دوال مساعدة لجلب أسئلة مادة معينة، استخراج بنك أسئلة، أو تكوين نموذج اختبار.
   - إدارة عمليات القراءة والكتابة في `LocalStorage`.
3. **`quiz.js`**:
   - آلة الحالة للاختبار (Quiz State Machine): الأسئلة، المؤشر الحالي، إجابات الطالب، حالة المؤقت.
   - التنقل بين الأسئلة (Next / Previous / Jump to Question).
   - التحقق من اكتمال الإجابات وإطلاق عملية التسليم.
4. **`results.js`**:
   - استقبال كائن الاختبار المكتمل وتصحيحه تلقائياً.
   - حساب الإحصائيات (الدرجة، النسبة، الأخطاء).
   - توليد بطاقات المراجعة التفصيلية وربط كل سؤال بمصدره وموقعه في المحاضرة.
   - حفظ النتيجة في سجل النتائج المحلي.
