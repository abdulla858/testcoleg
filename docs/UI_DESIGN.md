# دليل التصميم وهوية واجهة المستخدم (UI/UX Design System)

## 1. الهوية البصرية وفلسفة التصميم
- **العصرية والفخامة:** واجهة أنيقة، نظيفة، ومريحة للعين، تركز على القراءة المستمرة والتركيز أثناء حل الأسئلة وتجنب التشتيت.
- **اللغة والاتجاه (RTL First):** تصميم مبني أساساً من اليمين لليسار لدعم اللغة العربية بكل وضوح، مع سلاسة في دعم المصطلحات الإنجليزية داخل النصوص.
- **التجاوب التام (Responsive by Design):** تجربة استخدام مثالية على شاشات الجوال بمختلف أحجامها، والأجهزة اللوحية، والشاشات المكتبية الواسعة.

## 3. الخطوط والطباعة (Typography)
- استخدام خط عربي حديث وأنيق ومريح للقراءة الطويلة مثل `Tajawal` أو `Cairo` أو `Inter / System Font Fallbacks`.
- تدرج واضح للأوزان والعناوين:
  - العناوين الرئيسية `h1`: 1.75rem - 2.25rem (Bold)
  - العناوين الفرعية `h2`: 1.35rem - 1.6rem (Semi-bold)
  - نصوص الأسئلة: 1.15rem - 1.25rem (Medium)
  - الخيارات والشروح: 1rem (Regular)

## 4. المكونات البصرية الأساسية (Key UI Components)

1. **شريط التنقل العلوي (Navbar):**
   - شعار المنصة.
   - روابط الأقسام: الرئيسية، المواد، بنوك الأسئلة، النماذج، الاختبارات النصفية.
   - زر التبديل السريع بين الوضع النهاري والليلي.
   - زر السجل المحلي / الإعدادات.
2. **بطاقات المواد والنماذج (Cards):**
   - حواف ناعمة (`border-radius: 12px`).
   - تأثيرات تفاعلية لطيفة عند التحويم (`hover transition & transform translateY(-3px)`).
   - وسوم دلالية واضحة (Tags) للمستوى، الصعوبة، وعدد الأسئلة.
3. **واجهة الاختبار (Quiz Layout):**
   - رأس الاختبار: اسم المقرر، مؤقت الوقت، وزر إنهاء مبكر.
   - شريط التقدم: ملء متدرج مع مؤشر النسبة المئوية.
   - بطاقة السؤال: مساحة رحبة، نص واضح بحجم مريح.
   - خيارات الإجابة: بطاقات قابلة للنقر مع مؤشر اختيار وتغيير لون الحواف عند التحديد.
   - أزرار التحكم: (السابق، التالي، تسليم الاختبار).
4. **شاشة النتيجة والمراجعة (Result & Review):**
   - ملخص بياني دائري أو بطاقة نسبة مئوية ضخمة.
   - شبكة إحصائيات سريعة (صحيح، خطأ، تخطي).
   - بطاقات مراجعة بلون أخضر ناعم للإجابات الصحيحة ولون أحمر ناعم للأخطاء، مع توضيح نص المحاضرة ورقم الصفحة.
