# إرشادات الأمان والخصوصية (Security & Privacy Guidelines)

## 1. عدم وجود خادم ومزاياه الأمنية (Zero-Backend Security Model)
بما أن المشروع عبارة عن **Static Web Application**:
- لا توجد قواعد بيانات معرضة لثغرات SQL Injection.
- لا توجد بيئات خادم معرضة لثغرات Remote Code Execution.
- لا توجد جلسات خادم (Sessions) أو توكنات وصول معرضة للسرقة.

---

## 2. القواعد الصارمة لإدارة الأسرار والمفاتيح (Secret Management)
1. **يمنع منعاً باتاً وضع أي مفاتيح برمجية (API Keys) في كود الواجهة:**
   - يمنع تضمين مفاتيح Google Gemini أو OpenAI أو GitHub Tokens أو Firebase Credentials في ملفات JavaScript أو HTML.
   - إذا احتاج المشروع مستقبلاً لاستدعاء ذكاء اصطناعي أثناء التشغيل، يجب أن يتم ذلك عبر خادم خلفي آمن أو Cloudflare Worker منفصل ولا يوضع المفتاح في الواجهة إطلاقاً.
2. **عدم تخزين بيانات حساسة للمستخدمين:**
   - لا يتم طلب أو تخزين كلمات مرور، أرقام هواتف، أو بيانات دفع.

---

## 3. خصوصية التخزين المحلي (LocalStorage Privacy)
- جميع نتائج الاختبارات وسجلات الدرجات تُحفظ فقط في `LocalStorage` على جهاز الطالب نفسه.
- لا يتم إرسال أي إحصائيات أو تحليلات لأي سيرفر طرف ثالث.
- يتم تزويد الطالب بزر واضح في صفحة الإعدادات لحذف جميع بياناته المحلية بضغطة واحدة متى أراد ذلك.

---

## 4. الحماية من ثغرات الحقن في واجهة المستخدم (XSS Prevention)
- عند عرض نصوص الأسئلة والخيارات المقروءة من ملفات JSON:
  - استخدام `textContent` أو تعقيم الإدخال لمنع تشغيل أي وسوم HTML أو سكريبتات ضارة محقونة داخل ملفات البيانات.
  - تطبيق سياسة المحتوى الآمن (Content Security Policy) عند النشر.
