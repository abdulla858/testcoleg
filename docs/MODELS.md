# نظام النماذج التدريبية (MODELS.md)

## 1. المفهوم والتعريف
قسم النماذج مخصص حصرياً للملفات التي تحتوي على:
- نماذج اختبارات تدريبية (Model A, Model B, Exam Model).
- نماذج مراجعة معيارية محددة الأسئلة.

## 2. قواعد التعامل مع النماذج
- **نموذج مستقل**: كل نموذج يظهر في المنصة كنموذج تدريبي مستقل تماماً وله صفحة وبداية اختبار مستقلة.
- **الحفاظ على الأسئلة الأصلية**: لا يعاد صياغة الأسئلة ولا تتغير الإجابات المعتمدة في الملف الأصلي.
- **منع الخلط**: لا يتم خلط أسئلة النماذج مع أسئلة المحاضرات ولا مع بنوك الأسئلة ولا مع الاختبارات النصفية.

## 3. تمثيل البيانات
- `data/models.json`: البيانات الوصفية للنماذج (`id`, `courseId`, `title`, `durationMinutes`, `questionsCount`, `passingScore`).
- `data/model-questions.json`: أسئلة النماذج الخاصة بكل نموذج (`id`, `modelId`, `courseId`, `question`, `options`, `correctAnswer`, `explanation`).

## 4. وضع مادة البرمجة المتقدمة
- قسم النماذج لمادة البرمجة المتقدمة مهيأ ومصفر حالياً، وسيتلقى نماذجه فور إرسال وتصنيف ملفات النماذج.
